# Documentation

La documentation soutient la Factory ; elle n'est pas un core autonome.

## Sources actives

- `../strategy/` : vision, gouvernance, architecture, roadmap et standards ;
- `adr/` : décisions durables et backlog ;
- `project-status/` : état réel, matrice, action active et handoff ;
- `project-factory/` : processus et profils de projets dérivés ;
- `checklists/` : contrôles PR, statut et release ;
- `guides/`, `onboarding/`, `runbooks/` : usage opérationnel.

## Surfaces techniques

- Factory : `../factory/`
- Starters : `../starters/`
- Capabilities : `../capabilities/`
- Packages : `../packages/`
- Deployment : `../deployment/`
- Exemples : `../examples/`

## Règle de maintenance

Les documents actifs restent synthétiques. Git, les tags et GitHub Releases conservent les rapports et
étapes historiques. Un changement documentaire doit passer le link checker de `factory/quality/scripts`.
