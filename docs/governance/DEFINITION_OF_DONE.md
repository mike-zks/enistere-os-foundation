# Definition of Done

Une mission est terminée lorsque :

- le périmètre est respecté ;
- le code compile ;
- les tests applicables passent ;
- la conformité et les goldens passent ;
- la sécurité est traitée ;
- les migrations sont testées ;
- la documentation canonique est à jour ;
- le statut est calculé ;
- aucune documentation contradictoire ne reste active ;
- les preuves sont reproductibles.
