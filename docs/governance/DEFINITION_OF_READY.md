# Definition of Ready

Un composant est prêt à être implémenté lorsque :

- le besoin et le périmètre sont définis ;
- la spécification existe ;
- les contrats sont identifiés ;
- les dépendances et conflits sont déclarés ;
- les targets sont listées ;
- les critères de conformité sont écrits ;
- la migration est définie si nécessaire ;
- la prochaine action est unique.
