# Utilisateurs cibles et cas d’usage

## Utilisateurs

- développeur individuel ;
- startup ;
- petite ou moyenne équipe ;
- ESN ;
- architecte logiciel ;
- entreprise multi-produits.

## Modes d’entrée

- questionnaire interactif ;
- blueprint manuel ;
- idée en langage naturel ;
- cahier des charges ;
- projet existant, dans une phase ultérieure.

## Cas d’usage

- créer un système standard ;
- produire plusieurs applications Web ou Mobile ;
- choisir NestJS ou Spring pour une même API contractuelle ;
- ajouter Auth, Authorization, Files ou Notifications ;
- générer les clients API ;
- préparer les environnements ;
- vérifier la conformité ;
- ajouter une application après génération ;
- mettre à niveau une capability ou un runtime.
