# Positionnement produit

## Définition

Enistere OS Foundation combine :

- Project Factory ;
- Internal Developer Platform légère ;
- Architecture-as-Code ;
- moteur de composition ;
- système de conformité ;
- gestionnaire du cycle de vie applicatif.

## Enistere est

- une plateforme de description de systèmes ;
- un moteur de composition multi-applications ;
- une base d’industrialisation ;
- une couche de standardisation polyglotte ;
- un système d’évolution contrôlée.

## Enistere n’est pas

- un framework supplémentaire ;
- une collection de templates indépendants ;
- un outil no-code ;
- une IA autonome ;
- une obligation de microservices ou Kubernetes ;
- un générateur destructif limité au jour zéro.

## Différenciation

1. neutralité des contrats ;
2. interchangeabilité vérifiée des runtimes ;
3. capabilities composables ;
4. conformité calculée ;
5. évolution contrôlée.
